# Publishing

- After each completed OBS++ repository change, commit it and push it to Ethan's GitHub fork before finishing unless Ethan explicitly says not to publish it.
- Push only to the `origin` remote (`EthanSK/obs-plus-plus`). Never push directly to the upstream OBS repository.
- Treat a completed change as unfinished until the working tree is clean and the pushed branch contains the local commit.
- If committing or publishing is blocked, preserve the local change and report the exact blocker instead of silently leaving it only on this Mac.
